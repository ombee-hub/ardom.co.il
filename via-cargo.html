VIA CARGO

מערכת ERP לענף ההובלה וההפצה: כל המודולים הדרושים לחברה, בתוכנה אחת ואינטגרטיבית.

לתיאום פגישה
קרגו משלוחים

ניהול משלוחים, הפצה ומטען חלקי

VIA CARGO נשענת על מערכת המידע VIA של ערדום, והיא בנויה לתהליכים של חברות הובלה גדולות: מקליטת ההזמנה, דרך המרלו"ג וקווי ההפצה, ועד המסירה לנמען והחיוב.

המערכת פועלת בשילוב אפליקציות קצה שמחברות את המחסן, הנהגים ומרכזי השירות בזמן אמת, בתצורת Web Services.

מה המערכת מכסה

ניהול משרד ההובלה

הזמנות, תמחור, חיובים וגבייה במערכת אחת, משולבת עם הנהלת החשבונות.

משלוחים ומטען חלקי

ניהול משלוחים והפצה, כולל מטען חלקי (LCL).

אופטימיזציה בהפצה

ממשק דו-כיווני למערכת ROADNET לייעול ההובלה וההפצה של חבילות.

אפליקציות קצה

VILOG למחסן, VIGO לנהג משלוחים ו-QuickApp למרכזי שירות. לאפליקציות

ממשקים

המערכת יכולה לרוץ בחוות השרתים של ערדום, עם גיבוי, אבטחה ותמיכה. לשירותי IT
